סטטיסטיקות כניסה

האתר יושב על GitHub Pages, שאין לו סטטיסטיקות מובנות. לכן הסטטיסטיקות עובדות דרך GoatCounter – שירות חינמי, בלי עוגיות ובלי פרטים אישיים. הוא סופר כניסות לאתר וגם כמה פעמים נפתחה כל תפילה.

  1. פותחים חשבון חינמי ב־goatcounter.com/signup, ובוחרים קוד, למשל siddurchabad.
  2. כותבים כאן את הקוד ושומרים.
  3. בהגדרות החשבון ב־GoatCounter, תחת Settings ← Sites/Dashboard, אפשר לסמן שלוח הנתונים ציבורי לצפייה כדי שיוצג כאן.

חיבור ל־GitHub

השמירה מתבצעת ישירות לאתר דרך GitHub. בשביל זה צריך מפתח גישה אישי שמאפשר לשנות רק את המאגר של הסידור. המפתח נשמר רק בדפדפן הזה, ולא נשלח לשום מקום חוץ מ־GitHub.

  1. נכנסים ל־GitHub ← יצירת מפתח חדש (Fine-grained).
  2. שם: siddur-admin. תוקף: לבחירתך (למשל שנה).
  3. Repository access ← Only select repositories ← osmomusic/siddur.
  4. Permissions ← Repository permissions ← Contents: Read and write.
  5. Generate token, מעתיקים ומדביקים כאן.
